# Portfolio

A responsive portfolio starter built with React, TypeScript, and Vite.

## Getting started

```bash
npm install
npm run dev
```

## Project structure

- `src/components/layout` — shared page chrome
- `src/components/sections` — homepage sections
- `src/components/ui` — reusable interface primitives
- `src/data` — editable portfolio content
- `src/styles` — design tokens and component styles
- `src/types` — shared TypeScript models

Update `src/data/portfolio.ts` first when replacing the placeholder content with your own details.
